# BiCP v1.1.0

Settings and configuration update.

This release adds persistent settings to BiCP while preserving the local Competitive Programming workflow from v1.0.0.

## Highlights

- Settings window with categorized pages
- Persistent configuration stored in `config/setting.txt`
- Language preference persistence
- Editor font size and tab size configuration
- C++ compiler, standard, and optimization configuration
- Python interpreter configuration
- Editable default templates for C++ and Python
- Runtime application of settings after pressing Apply

## Bug Fixes

- Save and Save As now use separate actions and shortcuts.
- Rebuild is available from the toolbar.
- Generated bytecode and workspace runtime files are no longer tracked in Git.

## Known Limitations

- C++ execution still requires g++ to be installed and available in PATH.
- Syntax highlighting is not implemented yet.
