# BiCP v1.0.0 - Initial Stable Release

BiCP v1.0.0 is the first stable release of BiCP, a lightweight Windows desktop IDE designed specifically for Competitive Programming.

## Highlights

- C++ execution through local g++
- Python execution through the current Python interpreter
- Code editor with line numbers
- Run, Rebuild, and Stop workflow
- stdin input panel
- stdout/stderr output panel
- Compile error, runtime error, exit-code, and timeout reporting
- Save, Save As, and Find shortcuts

## Requirements

- Windows 10/11 x64
- g++ available in PATH for C++ execution

The packaged app bundles Python dependencies, but it does not bundle a C++ compiler.

## Known Limitations

- Syntax highlighting is not implemented yet.
- Settings are introduced in v1.1.0.
