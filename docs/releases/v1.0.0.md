# BiCP v1.0.0

Initial stable release of BiCP.

BiCP is a lightweight Windows desktop IDE for Competitive Programming. It focuses on a simple local workflow: write code, provide stdin input, compile or run, and inspect output without leaving the app.

## Highlights

- C++ editing and execution through local g++
- Python editing and execution through the current Python interpreter
- Line-numbered code editor
- Run, Rebuild, and Stop controls
- Input and output panels
- Compile error, runtime error, exit code, and timeout reporting
- Save, Save As, and Find shortcuts

## Basic Usage

1. Open BiCP.
2. Write C++ or Python code in the editor.
3. Add input in the INPUT panel.
4. Press Run or Rebuild.
5. Read stdout, stderr, and status details in OUTPUT.

## Known Limitations

- C++ execution requires g++ to be installed and available in PATH.
- Syntax highlighting is not implemented yet.
- Settings are introduced in v1.1.0, not v1.0.0.
